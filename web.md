## Podklady Pro Web

### Hero

**Headline:** Push-to-talk AI diktování pro vývojáře.

**Subheadline:** Mluv přímo do IDE, terminálu, chatu nebo dokumentace. YapTap přepíše řeč, doplní technický kontext a vloží hotový text tam, kde máš kurzor.

**CTA:** Drž zkratku. Řekni myšlenku. Pokračuj v práci.

### Feature Cards

- **Diktování bez přepínání kontextu**: žádné separátní okno, žádný editor navíc, jen vložení do aktivní aplikace.
- **Kontext z toho, co vidíš**: volitelný screenshot pomáhá modelu pochopit názvy proměnných, soubory, API a doménové termíny.
- **Post-processing podle tebe**: oprav gramatiku, přeformátuj text, přidej styl nebo použij vlastní data z endpointu.
- **Ovládej hlas rukama i nohama**: hotkey pro každý den, pedál pro maximální flow.
- **Postavené pro lokální i cloud AI**: transkripce běží přes OpenAI, kontext a post-processing přes OpenAI-kompatibilní endpointy.

### Developer Pitch

YapTap není jen diktafon. Je to tenká vrstva mezi systémovým vstupem, Web Audio API, OpenAI transkripcí a OpenAI-kompatibilními LLM endpointy. V Electronu drží globální hotkey, skrytý renderer nahrává zvuk, hlavní proces sestavuje prompt, řídí screenshot context reader, post-processing a vložení textu do aktuální aplikace.
